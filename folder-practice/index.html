01

첫 작업, 파일·폴더 정리

진입 임팩트 가장 큰 데모. 강의 첫 시연으로 최고.

최초 원본의 이미지 폴더를 그대로 사용해 파일명 변경, 분류, 변환, 요약을 시연합니다.
중복 파일도 자동으로 제거합니다.
작업이 끝나면 변경 내역을 마크다운 트리로 정리해 보여줍니다.
한 명령으로 정리·분류·변환·문서화까지 한 번에 보여주면, 여름사역 자료 관리의 감이 바로 잡힙니다.
🖼 Test/chapter3/Image 폴더에서 작업 — 원본 이미지 실습 6단계
1단계 // 폴더 내용 파악 
이 폴더 내용을 파악해줘.
2단계 // 파일명 동물 이름으로 
이 폴더 안의 이미지 파일 이름을 동물 이름으로 바꿔줘.
단, 원래 파일명의 번호는 유지해줘.
3단계 // 식성별 폴더 분류 
동물 이미지를 육식, 초식, 잡식으로 구분하고,
각각의 폴더를 만들어 정리해줘.
4단계 // 마크다운 트리 작성 
네가 정리한 내용을 md 파일로 트리 형식으로 보여줘.
5단계 // 이미지 jpg 변환 
이 폴더에 있는 이미지 파일은 모두 jpg로 바꿔줘.
6단계 // 동물 특징 요약 
각 동물들의 특징을 각각 한 줄로 요약하고,
여름성경학교 동물 비유 활동에 어떻게 연결할 수 있을지도 md 파일로 정리해줘.
